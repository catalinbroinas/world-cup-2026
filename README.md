# World Cup 2026

A responsive multi-page website exploring the 2026 FIFA World Cup, including participating teams, stadiums, group standings and the knockout stage.

## Technologies

* HTML
* SCSS
* JavaScript
* React
* Vite
* MDBootstrap 5
* Font Awesome

## Features

* Explore all 48 participating teams
* Browse the 12 tournament groups and standings
* Explore the 16 host stadiums
* View the knockout stage and match information
* Responsive layout across desktop, tablet, and mobile devices
* Accessible and semantic HTML structure
